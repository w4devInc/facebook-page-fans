# Facebook Page Fans (Archived)

> **⚠️ This project is archived and no longer maintained.** Facebook's Graph API and app review policies have changed significantly, making this plugin no longer viable.

## What It Did

A WordPress plugin that fetched Facebook Page fan (like) counts for pages linked via custom fields. If your post or custom post type contained a custom field with a Facebook Page URL or slug, this plugin would fetch the fan count and store it in a separate custom field.

## Why Archived

Facebook's Graph API has undergone major changes, including stricter app review processes, removal of certain public data endpoints, and tighter restrictions on the "Page Public Content Access" permission. This plugin is no longer compatible with the current API landscape and there are no plans to update it.

## Historical Requirements

- WordPress
- A Facebook Developer App with "Page Public Content Access" permission

## Installation (Historical)

Download the zip or clone the repo and install as a standard WordPress plugin.
